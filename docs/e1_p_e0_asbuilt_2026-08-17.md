## 1. Deliverable A — the §2.5 counters (committed `8794f3c`)

- `EOSSolver.eth_transport_delta` / `.eth_compression_delta` (int64,
  `def_readonly`): S = Σ n_bulk·T over the step-4c skip-set complement
  (!solid, !ts, !vacuum, !ring), n_bulk = the `gas_conservative` pair as
  int64. Transport bracket = [substep transport-block entry → after step-d
  flux], accumulated over substeps; compression bracket wraps the 4c loop.
  Reset at `step()` entry (the `boundary_flux_` idiom) → each read is that
  tick's delta. Units: raw Q16.16² (dequant = raw / 65536²).
- `tools/storm_ledger.py`: `counters()` reads both; `PER_TICK_COUNTERS`
  marks them never-diffed in the series; run totals accumulate into
  `eth_totals`; NEW pocket telemetry series `s_t_min_cell` / `s_n_at_tmin`
  (flat argmin-T gas cell + its bulk N per tick) — what §2.3's decision
  reads.
- **Inertness gate (hard, green):** suite failure set 47 known reds,
  name-sorted list byte-identical before/after; `bench_two_room --ticks 240
  --pf1b` per-field trajectory+final digests identical to the pre-change
  run, two post-change runs identical. (The audit's "36 reds" is stale —
  today's HEAD carries 47; the baseline was captured fresh before the first
  commit of this patch.)

sweep short-circuited on the first rail. No state-injection forcer was
used anywhere: geometry + dials + ignition seeding only.

## 4. Deliverable D — pinned N≈0.15 pocket variant

Committed scenario `POCKET` (same file): interior 10, tile 0.5, fuel 4×4
FURN, P-F1b, seed 12345. No dial engineering needed — the starved-fire
plateau IS the mid-band pocket. Measured on HEAD, 2400 ticks, pocket cell

| observable | value |
|---|---|
| n_bulk at pocket, while T > 1000 (2189 ticks) | **mean 0.1560, min 0.1447, max 0.2466** |
| n_bulk at peak-T tick / run min | 0.1470 / 0.1447 |
| peak T | 1820.6 game (tick 1379) |
| T climb | **no geometric compounding**: longest ≥×1.1/tick streak = 0 (plateau heating, ~combustion-fed) |
| peak local p* at pocket / map peak P | 1.1136 atm / 1.1136 atm |
| `t_max_phys_hits` / `work_clamp_hits` | **0 / 0** |

Reading for P-E4: at the natural mid-band pocket the compression-work
residual does NOT ignite on HEAD — the §2.4 static worst case (~8–14 atm)
requires a drainless convergent driver this scenario doesn't produce. The
committed determinism pin (`test_pocket_variant_is_deterministic`,
240-tick prefix ×2) freezes the scenario; its gate values freeze at P-E4
per §7. Nearby family points (8/4: N-hot-mean 0.158, peak T 1960; 12/5:
0.165, 1773) behave identically.
