## 0. Scope & the binding constraints it inherits

Arc B is the logic layer over the Arc A entity foundation: **SignalBus**
dataflow over integer signals, **sensors**, the **logic sweep**, the **pump**,
and the **automatic airlock**. Units are NOT signal endpoints (design §3e);
`button`/terminal stay format-reserved & inert (design §3d).

**Non-negotiable inheritances** (the escalation triggers — STOP and bring Erik
in rather than break any):

1. **§5a accessor shape is forever-contract.** Sensors read through ONE
   accessor: host mirror (CPU path) or a `(n_sites × n_channels)` int32 gather
   buffer (resident path, later). Deterministic **id-order** sites, **Q16.16**
   values, **no dequantize in the sim path**. Per the S8c-concurrency
   constraint, Arc B **stubs the accessor to the host mirror and builds NO
   resident gather kernel** — the seam is the deliverable, the kernel rides a
   later slot. Nothing in Arc B touches `physics_runner.py`'s resident tick or
   the CUDA build.
2. **The 2-tick latency contract and the member-id sweep order are canon.**
   (This doc §2 pins the exact mechanics; changing them = reopen the design.)
3. **Dormancy guarantee.** An entity-free level and every existing level hash
   **byte-identical** to today. Existing goldens are **never** re-baselined by
   this arc. New logic must be dormant on levels that declare no wires/sensors.
4. **Determinism (iron rules).** Signals/sensor/node state are synced sim state
   — Q16.16 integer only, digest-gated, joined to the recorder. Integer tick
   counts for timers/edges. No RNG, no float, no dict-order dependence.

## 1. The `[[wire]]` format (Erik's call: dotted from/to)

A wire is a **first-class level object** — a selectable, copyable thing (the
editor's two-click wire tool; clump copy/paste preserves internal wires). It
binds one emitter's **signal** to one consumer's **input**.

```toml
[[wire]]
from = "sensor_1.pressure"        # "<source_id>.<signal_name>"
to   = "decider_1.in"             # "<target_id>.<input_name>"

[[wire]]
from = "decider_1.out"
to   = "tag:blast_doors.close"    # tag target → fans out in member-id order
```

### 1a. Grammar & parsing (in `level_loader._parse_wires`, new)

- `from = "<id>.<signal>"`. `<id>` is an entity id (loader slug charset;
  cannot contain `.`), `<signal>` a signal the source class emits (incl. the
  free `alive`). Split on the **last** `.` is unnecessary — ids forbid `.`, so
  split on the first; validate both halves.
- `to = "<target>.<input>"` where `<target>` is either `<id>` or
  `tag:<name>`. `<input>` is a declared input on the target class(es).
- Empty/malformed strings → hard `ValueError` naming the wire index.

### 1b. Validation (registry is the validator, design §3b)

At load, after entities are parsed (ids + tags known):
- **Source signal exists:** `<signal> ∈ all_signals(source.class)`; else hard
  error. Source id exists; else hard error (a wire is authored intent — a
  dangling *source* is a harder error than a dangling entity_ref; but to match
  §3a "dangling refs warn", we **warn** on a dangling source/target id and drop
  the wire, so a runtime-destroyed target authored defensively is legal). →
  **PIN: dangling id in a wire WARNS + drops the wire** (consistent with §3a);
  a **bad signal/input NAME on an existing class hard-errors** (a typo, not a
  destroyed target).
- **Target input exists:** `<input> ∈ target.class.INPUTS`. For `tag:` targets,
  **every** tagged member must declare the input; a member lacking it → hard
  error (naming the member) — no silent partial fan-out.
- **Unit rejection (§3e):** `from`/`to` naming a `[[spawn]]` unit → hard error
  (units are not signal endpoints in v1). Same rule the A3 entity_ref loader
  already enforces; shared helper.
- **Value-input arity (§3, new pin):** an input declared `SINGLE` (value-
  carrying — decider/filter `in`, `gate_not.in`) accepts **exactly one** wire;
  a second wire to it → hard error. `OR`/`AND`/`EDGE` inputs accept many.

### 1c. Runtime wire table

`level_lib` writer gains `format_wire_lines` (managed `[[wire]]` block, byte-
stable round-trip — the A2 test extends over wires). The loader materializes
wires into a **resolved fan-out table** on `LevelData`: `list[Wire]` with
`(source_ordinal, signal, target_ordinal, input, aggregation_mode)`, tag
targets pre-expanded to one `Wire` per member **in member-id order** (§3a
single ordering rule). Tag expansion is frozen at load — a runtime-spawned
member cannot join a tag (units aren't entities; entities don't spawn in v1).

## 2. The SignalBus & the two-tick latency contract

### 2a. Data structure

`SignalBus` (`src/simulation/signal_bus.py`, sim-side — NOT in the import-light
`entities` package). Two integer buffers keyed by **(emitter_ordinal,
signal_name)**:

- `pub` — the values **readable this tick** (published).
- `stg` — where node/actuator writes for **next tick** land (staged).

Both are dense `int64` arrays indexed by a frozen **signal-slot table** built
at load (one slot per `(entity, emitted-signal)` pair, in `(ordinal, name)`
order — the same order `serialize_signal_state` hashes). Dense + frozen ⇒ no
dict-order, O(1) reads, trivially digestible.

### 2b. The slot-9e sub-order (THE contract)

Slot 9e (after 9d ignition, before the recorder snapshot) becomes, per tick T:

```
(a) SENSOR SAMPLE   — each sensor reads this tick's post-physics fields via the
                      §5a accessor and writes pub[sensor.signal] = samp(T).
                      Same-tick visible. (Sensors read FIELDS/units, never
                      signals → no ordering dependence among sensors.)
(b) LOGIC SWEEP     — each node, in entity-id order, reads pub (this tick's
                      sensor values + LAST tick's node outputs), writes
                      stg[node.out]. Nodes NEVER read stg → a node cannot see
                      another node's this-tick output → order-independent.
(c) EMIT alive+door — every entity's free `alive` and the door's `is_open` are
                      written to pub for the CONSUMERS below (alive/is_open are
                      state, same-tick visible like sensors).
(d) INPUT RESOLVE   — for each actuator (door, pump), aggregate its incoming
                      wires reading pub (§2d), producing this tick's input
                      values (want_open, pump inject/extract).
(e) ACTUATOR SWEEP  — pump edits (this tick), then the existing door structural
                      sweep (want_open latch, id order).
(f) SWAP            — pub[node-signals] ← stg[node-signals]. Sensor & alive &
                      is_open slots are overwritten fresh each tick at (a)/(c),
                      so they are not swapped.
```

The recorder/digest snapshot (after 9e) hashes `pub` **post-swap** — i.e. next
tick's node outputs + this tick's sensor/alive/is_open values. Pinned so the
`__signals__` section is a deterministic function of tick state.

### 2c. Worked latency (the "2 ticks", golden-tested)

Canonical path **sensor → decider → door** (one node hop):

| tick | (a) sensor | (b) decider reads pub | (d) door input reads pub | (e) door flip | solver sees |
|---|---|---|---|---|---|
| T   | writes `pub[s]=S(T)` | reads `pub[s]=S(T)` → `stg[d]=f(S(T))` | reads `pub[d]=f(S(T-1))` | old | — |
| T+1 | S(T+1) | … | reads `pub[d]=f(S(T))` → want_open | **flip** | — |
| T+2 | | | | | step-6 restamp → **field effect** |

**Sensor sample → world effect = 2 ticks** (one node hop is same-tick in, the
door's structural restamp is the +1, the swap is the +1). Each **additional
node hop adds one tick** (filter before decider ⇒ 3-tick path). The golden
(B6) pins the exact tick of first flip for the canonical airlock chains.

### 2d. Input aggregation (design §4, extended for the node set)

Each input declares an **aggregation mode**. §4 pins two; the node set needs
two more (an *addition*, not a change — the door's held/edge semantics are
untouched, escalation trigger 2 safe):

| mode | meaning | used by |
|---|---|---|
| `OR` (=`INPUT_HELD`) | 1 if **any** driving wire's signal ≠ 0 (while-held) | door `open`/`close`, pump `inject`/`extract`, `gate_or.in` |
| `EDGE` (=`INPUT_EDGE`) | fires **once** if any driving wire **rose** 0→≠0 this tick vs its own prev (edge state is a synced runtime row) | reserved; airlock uses level (held) triggers in v1 |
| `AND` (new) | 1 iff **every** driving wire ≠ 0 (empty ⇒ 0) | `gate_and.in` |
| `SINGLE` (new) | the one driving wire's **integer value** verbatim (value-carrying); load-time arity=1 | `decider.in`, `filter.in`, `gate_not.in` |

`INPUT_PRIORITY` (close-beats-open) resolves complementary conflicts **after**
aggregation, unchanged. `require_alive` (decider sugar) ANDs the source
entity's `alive` into the aggregated value — resolved via the wire's known
`source_ordinal` (§3), so a dead source zeroes the decider regardless of the
stale signal value.

## 3. The §5a sensor accessor seam (binding interface)

`EntityFieldAccessor` (`src/simulation/sensor_accessor.py`). Built **once at
load** from the static site index; read each tick at 9e(a).

```
build_site_index(sensors) -> SiteIndex          # (site → tile, channel), id order
accessor.sample(channel, fy, fx) -> int         # Q16.16, one site
accessor.area(channel, disc_tiles) -> (sum, n)   # integer sum + live non-solid count
```

- **CPU path (this arc):** `sample`/`area` read the **host mirror** (`gmap`
  fields) directly. This is the stub. The values are already Q16.16 integers on
  the mirror; **no dequantize**.
- **Resident path (later, NOT this arc):** the same two methods are served by
  the `(n_sites × n_channels)` int32 gather buffer. Arc B code calls only
  `sample`/`area` and **must not care** which backing answers. The site index
  order (id order) and the int32 Q16.16 contract are frozen here.
- **Channels** map sensor kinds → gmap fields: `pressure`→ materialized `P`
  (atmosphere), `temperature`→`temperature`, `o2`→ O₂ partial (per §5b below),
  `smoke`→`smoke`, `water_depth`→`water_depth`, `fire`→`fire`. `clock`,
  `door.is_open`, `sensor_motion` do **not** go through the field accessor
  (§5b) — they read the tick counter / a signal / units respectively.

★ **`is_ambient` is not static** (S8a finding): sensors never cache
per-level anything combat can mutate. The site→tile map is static (sample
tiles are authored), but the *values* are always read live each tick — no
per-level field snapshot is retained.

## 4. Sensor catalog (v1, design §6)

All physical-by-default; `intangible` per instance. Each sensor declares a
`sample_tile` = the faced **air** tile (offset from the possibly-solid body
tile, design §5 — sampling a wall-mounted body reads 0 forever and would slam
blast doors at t=0). Behavior when the sample tile turns solid/vacuum is the
honest reading of that tile — no special case.

Field sensors (`pressure`, `temperature`, `o2`, `smoke`, `water_depth`,
`fire`): emit `value` (Q16.16). Optional `area` (length_m radius): the disc is
`dist < radius` (FieldEdit strict rule), masked to **currently non-solid**
tiles, integer `area()` sum ÷ live non-solid count, **floor** (§6). `r_tiles`
& disc quantized once at load (editor §4 canonical rule). The non-solid set
legitimately changes when a wall in the disc is destroyed — physics being
sensed, not drift.

- **`clock`:** emits `value` = an integer counter derived from the tick
  (`tick % period` or a phase compare — the class declares the period, snapped
  at load). No field read.
- **`door.is_open`:** not a class — the **door emits its `is_open` signal**
  (already declared, inert in Arc A; Arc B makes 9e(c) write it). Wire
  `door_x.is_open → …` directly.
- **`sensor_motion`:** emits `value` = count of living units with
  `dist²(sensor_tile, unit_anchor) ≤ r_tiles²` AND (if `needs_los`)
  `has_los(sensor_tile → unit_anchor)` with the **sensor as Bresenham origin**
  (has_los is asymmetric — origin pinned). `faction_filter = any | team-int`;
  `min_footprint` compares the unit's declared footprint field. Reads
  `sim.units` in unit-id order — deterministic, integer.

`hp_below`/`hostiles-of`/`chip.carried_by`/`win(...)` are **stack-2 riders**,
format-reserved, NOT built here.

## 5. The node set (design §4/§5)

L0 node classes in `src/simulation/entities/nodes.py` (schema, import-light) +
runtime in `src/simulation/logic_nodes.py` (the sweep-side behavior, gmap-free
— pure SignalBus I/O per §4). Every node `intangible` default-True? **No** —
"physical by default, `intangible=true` per node" (design §5): nodes default
physical but are typically placed intangible; the class defaults `INTANGIBLE`
appropriately per kind and the instance overrides.

- **`decider`:** INPUT `in` (`SINGLE`). FIELDS `comparator`
  (enum `gt|ge|lt|le|eq|ne`), `threshold` (Q16.16 — authored in the input's
  physical unit, quantized once at load by the same meters-first rule as door
  length/filter τ), `require_alive` (bool, default false). SIGNAL `out` (0/1).
  Emits `out = 1` iff `cmp(in_value, threshold)` AND (require_alive ⇒ source
  alive). Prev-read/next-write.
- **`gate_and` / `gate_or`:** INPUT `in` (`AND` / `OR`, many wires). SIGNAL
  `out` (0/1) = all / any driving signals ≠ 0.
- **`gate_not`:** INPUT `in` (`SINGLE`). SIGNAL `out` = `1 - (in≠0)`.
- **`filter`:** INPUT `in` (`SINGLE`). FIELDS `tau_s` (length_m-style seconds,
  snapped once at load to `k = round(log2(τ·tps))`, k≥0; the editor shows the
  snapped effective τ). SIGNAL `out` (Q16.16). Integer EMA with shift `k`:
  state carries **k guard bits**, rounds-to-nearest before the shift (kills the
  truncation-park bug, design §4). **Runtime digest row:** the guard-bit
  accumulator (synced) + any edge-detector prevs.

Node runtime state (EMA accumulator, EDGE prev-values) are **synced runtime
rows** (`runtime_digest_rows`, the A4 mechanism) — hashed, recorded, in
`get_state`. Class schema declares them via a new `runtime_digest_rows`
override; zero mechanism surgery.

## 6. The pump (N-feed actuator, design §6b)

Class `pump` (`entities/nodes.py` schema + `logic_nodes.py`/a small
`pump_system.py` runtime). Post-EOS, nothing injects "pressure" — the pump is a
**gas-mass (N) feed**.

- INPUTS `inject`, `extract` (`OR`/held). FIELDS `rate` (atm/s, authored),
  `target_atm` (Q16.16), `port_dx`/`port_dy` (the **port tile** offset —
  distinct from the solid body, else the skip-solid mask vetoes the pump's own
  edit). SIGNAL `at_target` (0/1, with a declared **hysteresis band** default
  ±0.05 atm — no bang-bang chatter), `alive`.
- **Per-tick quantum** `ΔN` computed **once at load**: from `rate` via
  `ΔN = P/(C·T_std)` at standard temperature, integer Q16.16 (door-2 rule).
- **Inject:** add `ΔN` at the fixed standard O₂/N₂ mix at the port tile.
  **Extract:** remove `ΔN` **proportional to the tile's current composition**,
  **clamped at zero** — the atmosphere edit path gets an explicit clamp (an
  unclamped remove drives N negative → garbage to the Helmholtz solver).
- Atmosphere edits are structural-ish field writes at 9e(e) **before** the door
  sweep; they reach the solver next tick (consistent one-tick story). Uses the
  existing gmap atmosphere-edit primitive + the new zero-clamp.

Intent note (not a bug): a pump feeding a breached room makes venting
non-terminating (steady source vs vacuum sink → steady wind). Correct physics.

## 7. The automatic airlock_controller (design §6b; B5, HUMAN-TEST)

Class `airlock_controller` — an L0 **state machine** entity (SignalBus-only
I/O). Wired to: a chamber presence plate (`sensor_motion`) `in`; an **inner**
and **outer** door (drives their `close`/`open`); a **pump** (drives
`inject`/`extract`, reads `at_target`); reads both doors' `is_open`. Emits
`busy` (1 while cycling) + `alive`.

**v1 state machine** (single automatic cycle; the acceptance level's showcase):

```
IDLE            presence.count==0 → stay; ≥1 in chamber → CLOSING (busy=1)
CLOSING         drive both doors close; both is_open==0 → EQUALIZE
EQUALIZE        drive pump toward far-side target_atm; at_target → OPEN_FAR
OPEN_FAR        drive far door open; presence.count==0 (chamber cleared) → RESEAL
RESEAL          drive far door close; is_open==0 → REPRESSURIZE
REPRESSURIZE    drive pump toward near-side target; at_target → OPEN_NEAR → IDLE
```

State + phase are **synced runtime rows** (integer state enum + any dwell
counter — integer ticks). Which side is "far" and the two targets are authored
fields (`target_far_atm`, `target_near_atm`). All transitions read `pub`
(prev-tick) and drive via wires — **no direct entity references**, so the
controller's list position is never observable. Timing/feel is Erik's B5
HUMAN-TEST gate; the state graph is deterministic and golden-testable
independent of feel.

**Accepted gap (simplest honest design):** v1 is one chamber, two doors, one
pump, level (not edge) triggers, no crush/anti-cycle beyond
occupancy-blocks-close (inherited from the door sweep). Multi-occupant races
resolve by the deterministic presence count; a unit re-entering mid-cycle just
holds the machine in its current wait state.

## 8. Digest, recorder, dormancy

- **`__signals__` populated (SIGNAL_SECT_V1):** at snapshot, emit
  `(emitter_ordinal, signal_name, pub_value)` for every non-`alive` signal
  slot, sorted `(ordinal, name)` — exactly what `serialize_signal_state`
  already expects (Arc A defined it empty). `alive` stays excluded (hashed only
  as the `__entity__` row, critique 7).
- **Node/pump/airlock runtime state** joins `__entity__` via
  `runtime_digest_rows` (the A4 per-class block) — EMA accumulators, edge
  prevs, controller state/dwell. Integer, synced.
- **Dormancy:** a level with **no `[[wire]]` and no logic/sensor entities**
  produces an **empty bus** (`serialize_signal_state(()) == SIGNAL_SECT_V1\n`,
  Arc A's stable empty) and no new runtime rows → **byte-identical** digest to
  today. The 9e sub-steps (a)–(f) are **gated on `sensors ∪ nodes ∪ wires
  non-empty`** exactly as the door sweep is gated on `_doors`. Existing goldens
  untouched — **no re-baseline** (escalation trigger 3).

## 9. Determinism ledger

Integer-only (Q16.16); every sweep in **entity-id / member-id order**; dense
frozen signal-slot & wire tables (no dict-order); sensors read fields/units
before any node reads signals (no sensor↔node order coupling); nodes
prev-read/next-write (no node↔node order coupling — the order-independence
proof); no RNG anywhere in the logic path; timers/edges are integer tick
counts. All new synced state (bus + runtime rows) joins the digest + recorder.

## 10. Patch breakdown (build order on `arc-b-logic`)

Each patch: unit tests + the **dormancy assertion** (existing goldens
byte-untouched — a fast check that a fixture entity-free level's digest is
unchanged). Patches stack on the branch; no individual merge to main.

- **B1 — SignalBus + `[[wire]]` format + 9e expansion + accessor seam.**
  Bus buffers + slot table; `_parse_wires` + validation + `level_lib` writer +
  round-trip test; 9e sub-order (a)–(f) with only the existing door sweep as
  actuator (door emits `is_open`, `open`/`close` inputs drive `want_open` via
  wires — replacing the dev latch as the real driver); `__signals__` populated;
  dormancy proof. **Gate: dormancy + unit tests.** *(button/terminal
  format-reserved classes land here, inert.)*
- **B2 — node set** (decider, gate_and/or/not, filter) + the AND/SINGLE
  aggregation modes + `require_alive`. **Gate: unit tests (each node's truth
  table + filter τ-snap/guard-bit + prev/next latency) + dormancy.**
- **B3 — v1 sensor catalog** through the §5a accessor (field sensors +
  area-mean + clock + door.is_open emit + sensor_motion geometry). **Gate: unit
  tests (each sensor's sample, area-mean mask, LOS asymmetry, faction filter) +
  dormancy.**
- **B4 — pump** (N-feed, quantum, inject/extract + zero-clamp, port tile,
  hysteresis). **Gate: unit tests + N-conservation on inject/extract + dormancy.**
- **B5 — airlock_controller** state machine. **Gate: state-graph unit tests +
  the E2E airlock fixture cycles deterministically. FEEL-ADJACENT →
  HUMAN-TEST before merge.**
- **B6 — logic golden + E2E fixture level + cross-machine attestation** (a
  small level with a sensor→filter→decider→door feedback loop, trajectory-
  hashed; the airlock fixture). Canon fold into `engine/16 §8`. **Gate: the new
  logic golden green cross-machine + full suite + HUMAN-TEST feel of
  doors/sensors in play.**

Arc-close: fold as-built into canon `engine/16 §8`, archive brainstorms,
delete the worktree/branch after merge.

## 11. Open points for the critique (adversarial lenses)

1. **Determinism / order-independence:** is the 9e sub-order (a)–(f) truly
   order-independent for nodes? Does `require_alive` reading the source's
   `pub[alive]` at (b) race with (c)'s alive-emit? (Pin: alive is emitted at
   the TOP alongside sensors, before (b) — restructure if (c) is too late.)
   Does the pub-post-swap digest capture the intended tick's state?
2. **Dormancy / digest / scope:** does any 9e step run (mutating state or
   digest bytes) on an entity-free or wire-free level? Is the empty-bus digest
   provably the Arc A empty? Do the new runtime rows stay absent when no nodes
   exist? Any accidental golden touch?
3. **Protocol / latency / failure-modes:** is the 2-tick table right, and does
   it match "sensor→actuation 2 ticks"? Value-input arity=1 — does the airlock
   need multi-drive value inputs anywhere (forcing a rethink)? Pump zero-clamp
   + Helmholtz — is N-negative truly impossible? Fail-deadly/fail-safe: does a
   destroyed sensor correctly zero its consumers (fail-deadly) and does
   `require_alive` correctly make it fail-safe? The `[[wire]]` dangling-vs-typo
   split — right call?
