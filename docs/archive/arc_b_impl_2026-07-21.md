## 0. Scope & the binding constraints it inherits

Arc B is the logic layer over the Arc A entity foundation: **SignalBus**
dataflow over integer signals, **sensors**, the **logic sweep**, the **pump**,
and the **automatic airlock**. Units are NOT signal endpoints (design §3e);
`button`/terminal stay format-reserved & inert (design §3d).

**Non-negotiable inheritances** (the escalation triggers — STOP and bring Erik
in rather than break any):

1. **§5a accessor shape is forever-contract.** Sensors read through ONE
   accessor: host mirror (CPU path) or a `(n_sites × n_channels)` int32 gather
   buffer (resident path, later). Deterministic **ordinal (file-order) sites**,
   **Q16.16** values, **no dequantize in the sim path**. Per the S8c-concurrency
   constraint, Arc B **stubs the accessor to the host mirror and builds NO
   resident gather kernel** — the seam is the deliverable, the kernel rides a
   later slot. Nothing in Arc B touches `physics_runner.py`'s resident tick or
   the CUDA build. *(v2: the channel SET is frozen here to include a solidity
   channel — see §3 — so `area()` is backable by the buffer alone. Adding a
   channel to the enumeration is not a change to the frozen shape/dtype/order.)*
2. **The 2-tick latency contract and the ordinal sweep order are canon.**
   (§2 pins the exact mechanics; changing them = reopen the design.)
3. **Dormancy guarantee.** An entity-free level AND every existing level
   (including door-only levels like `test_level`/`door_test`) hash
   **byte-identical** to today. Existing goldens are **never** re-baselined by
   this arc. New logic is dormant on levels that declare no wires/sensors/nodes.
4. **Determinism (iron rules).** Signals/sensor/node state are synced sim state
   — Q16.16 integer only, digest-gated, joined to the recorder. Integer tick
   counts for timers/edges. No RNG, no float, no dict-order dependence.

## 1. The `[[wire]]` format (Erik's call: dotted from/to)

A wire is a **first-class level object** — a selectable, copyable thing (the
editor's two-click wire tool; clump copy/paste preserves internal wires). It
binds one emitter's **signal** to one consumer's **input**.

```toml
[[wire]]
from = "sensor_1.pressure"        # "<source_id>.<signal_name>"
to   = "decider_1.in"             # "<target_id>.<input_name>"

[[wire]]
from = "decider_1.out"
to   = "tag:blast_doors.close"    # tag target → fans out in ordinal order
```

### 1a. Grammar & parsing (`level_loader._parse_wires`, new)

- `from = "<id>.<signal>"`. `<id>` is an entity id (loader slug charset —
  cannot contain `.`), so split on the first `.`; validate both halves.
- `to = "<target>.<input>"` where `<target>` is `<id>` or `tag:<name>`;
  `<input>` a declared input on the target class(es).
- Empty/malformed strings → hard `ValueError` naming the wire index.

### 1b. Validation (registry is the validator, design §3b)

After entities are parsed (ids + tags known):
- **Source signal exists:** `<signal> ∈ all_signals(source.class)` (incl. the
  free `alive`); else hard error (a typo, not a destroyed target).
- **Dangling id WARNS + drops the wire** (consistent with §3a's dangling-ref
  rule — a runtime-destroyed target authored defensively is legal); a **bad
  signal/input NAME on an existing class HARD-ERRORS**.
- **Target input exists:** `<input> ∈ target.class.INPUTS`. For `tag:` targets,
  **every** tagged member must declare the input; a member lacking it → hard
  error naming the member (no silent partial fan-out).
- **Unit rejection (§3e):** `from`/`to` naming a `[[spawn]]` unit → hard error
  (shared helper with the A3 entity_ref loader).
- **Value-input arity (§2d):** a `SINGLE` input (decider/filter `in`,
  `gate_not.in`) accepts **exactly one** wire; a second → hard error.
  `OR`/`AND`/`EDGE` inputs accept many. *(Multi-sensor predicates compose
  through `gate_or`/`gate_and`, not by fanning two sources into one value pin —
  verified sufficient for the v1 airlock.)*

### 1c. Runtime wire table

`level_lib` gains `format_wire_lines` (managed `[[wire]]` block, byte-stable
round-trip — the A2 test extends over wires). The loader materializes a
**resolved fan-out table** on `LevelData`: `list[Wire]` of
`(source_ordinal, signal, target_ordinal, input, aggregation_mode)`, tag
targets pre-expanded to one `Wire` per member in **ordinal order** (§3a). Tag
expansion is frozen at load (entities don't spawn in v1; units aren't entities).

## 2. The SignalBus & the two-tick latency contract

### 2a. Data structure (built only when logic exists — D1)

`SignalBus` (`src/simulation/signal_bus.py`, sim-side — NOT in the import-light
`entities` package). Built at load **iff `sensors ∪ nodes ∪ wires ≠ ∅`**;
otherwise the sim carries **no bus** and `get_state`/recorder pass `signals=()`
exactly as today.

The **signal-slot table** enumerates only signals that are **wire-referenced OR
emitted by a sensor/node** — never "every entity's every signal". So an unwired
door contributes **no** slot; a door whose `is_open` is wired to something gets
one. Slots are ordered `(ordinal, name)` — identical to
`serialize_signal_state`'s sort (`serialize.py:183`). Two dense `int64` buffers
over that table:

- `pub` — values **readable this tick** (published).
- `stg` — where node/actuator writes for **next tick** land (staged).

Dense + frozen ⇒ no dict-order, O(1) reads, trivially digestible.

### 2b. The slot-9e sub-order (THE contract — D2/D3/D4/D13 folded)

Two independently-gated pieces inside slot 9e:

- **The door structural sweep stays gated on `if self._doors`** (unchanged from
  Arc A `door_system.sweep_doors`) — it always runs on a door level.
- **The logic block runs iff the bus exists** (`sensors∪nodes∪wires ≠ ∅`).

When the bus exists, the logic block executes, then the door sweep. Per tick T:

```
(a) SAMPLE + STATE EMIT
      · each sensor reads this tick's post-physics fields via the §5a accessor
        and writes pub[sensor.signal]=samp(T); a DEAD sensor writes 0 (D13,
        fail-deadly — never left stale).
      · every wired entity's free `alive` and every wired door's `is_open` are
        written to pub NOW (before the logic sweep) — so require_alive and
        door.is_open→node reads are current-tick (D4).
(b) LOGIC SWEEP  — each node, in ORDINAL order, reads pub (this tick's sensor +
      alive/is_open values + LAST tick's node outputs) and writes stg[node.out].
      Nodes NEVER read stg → a node cannot see another node's this-tick output →
      order-independent (the proof; verified sound by the critique).
(c) INPUT RESOLVE — for each actuator with incoming wires, aggregate them
      reading pub (§2d) → this tick's input values. A door with NO incoming
      open/close wire is skipped here and keeps its Arc-A want_open latch (D3).
(d) ACTUATOR SWEEP — pump edits (this tick), then the door structural sweep
      (want_open latch, ordinal order).
(e) SWAP — pub[node-signals] ← stg[node-signals]. Sensor / alive / is_open
      slots are refreshed each tick at (a), so they are not swapped.
```

The recorder/digest snapshot (after 9e) hashes `pub` **post-swap** — next
tick's node outputs + this tick's sensor/alive/is_open values. Deterministic.

### 2c. Worked latency (the "2 ticks", golden-tested — D14/N2)

Canonical path **sensor → decider → door** (one node hop):

| tick | (a) sensor | (b) decider reads pub | (c) door input reads pub | (d) door flip | solver sees |
|---|---|---|---|---|---|
| T   | writes `pub[s]=S(T)` | reads `pub[s]=S(T)` → `stg[d]=f(S(T))` | reads `pub[d]=f(S(T-1))` | old | — |
| T+1 | S(T+1) | … | reads `pub[d]=f(S(T))` → want_open | **flip** | — |
| T+2 | | | | | step-6 restamp → **field effect** |

Anchor precisely: sample → **door-state flip = 1 tick**; sample → **physical
field effect = 2 ticks** (the parent design's "sensor→actuation = 2 ticks"
means the *world* effect). **Each additional node hop adds exactly one tick**
(nodes read the upstream's previous swap, never `stg` — hop count = tick count).
The B6 golden pins the exact flip tick for the canonical airlock chains.

### 2d. Input aggregation (design §4, extended — nit folded)

Each input declares an **aggregation mode**. §4 pins two; the node set adds two
(an *addition* — the door's held/edge semantics are untouched, trigger-2 safe).
**These new modes require extending `schema.py`'s `INPUT_*` vocabulary and
`_validate_class` mode guard** (`schema.py:337-340`) — Arc B's own package.

| mode | meaning | used by |
|---|---|---|
| `OR` (=`INPUT_HELD`) | 1 if **any** driving wire ≠ 0 (while-held) | door `open`/`close`, pump `inject`/`extract`, `gate_or.in` |
| `EDGE` (=`INPUT_EDGE`) | fires **once** on a 0→≠0 rise vs its own synced prev row | reserved; airlock uses level (held) triggers in v1 |
| `AND` (new) | 1 iff **every** driving wire ≠ 0 (empty ⇒ 0) | `gate_and.in` |
| `SINGLE` (new) | the one driving wire's **integer value** verbatim; arity=1 | `decider.in`, `filter.in`, `gate_not.in` |

`INPUT_PRIORITY` (close-beats-open) resolves conflicts **after** aggregation,
unchanged. `require_alive` (decider) ANDs the source entity's `pub[alive]`
(available at (b) after the (a) emit — D4) via the wire's known
`source_ordinal`, so a dead source zeroes the decider this tick.

**Fail-deadly vs fail-safe is direction-dependent (D13, design §4 "author picks
per wire"):** a bare `p<0.8 → close` wire is **fail-deadly** — a dead sensor
reads 0 (D13), `0<0.8` fires → door **slams** (safe for a *blast* door). Adding
`require_alive` makes it **fail-passive** — a dead sensor forces the decider to
0, the door is not commanded. Which is "safe" depends on the door; the author
chooses per wire. The doc does not editorialize "require_alive = safe".

## 3. The §5a sensor accessor seam (binding interface — D6/D7/D8/D9)

`EntityFieldAccessor` (`src/simulation/sensor_accessor.py`). Built once at load
from the static site index; read each tick at 9e(a).

```
build_site_index(sensors) -> SiteIndex           # (site → tile, channel), ordinal order
accessor.sample(channel, fy, fx) -> int           # Q16.16, one site
accessor.area(channel, disc_tiles) -> (sum, n)     # integer sum + live non-solid count
```

- **CPU path (this arc):** `sample`/`area` read the **host mirror** (`gmap`
  fields) directly — the stub. Values are already Q16.16 on the mirror; **no
  dequantize**.
- **Resident path (later, NOT this arc):** the same two methods are served by
  the `(n_sites × n_channels)` int32 gather buffer. Arc B calls only
  `sample`/`area` and **must not care** which backing answers. The ordinal site
  order and the int32 Q16.16 contract are frozen here.
- **Channel map (frozen v2):**

  | channel | gmap field | tile family | notes |
  |---|---|---|---|
  | `pressure` | materialized `atmosphere` P | **air** | 0 on solid/vacuum ✓ |
  | `smoke` | `gas[BLACK_SMOKE]` | **air** | ✓ |
  | `water_depth` | `water_depth` | **air/floor** | ✓ |
  | `temperature` | `temperature` | **solid body** (D7) | air carries no temperature |
  | `fire` | `fire` | **flammable body** (D8) | fire only on flammable tiles |
  | `o2` | `gas[O2]` **mass density** (D9) | **air** | NOT partial pressure — no `p_O2` field exists; density is the pure-gather channel (T-dependence documented) |
  | `solid` | `solid`/occupancy mask (D6) | — | so `area()`'s live non-solid count is derivable from the buffer alone |

  `clock`, `door.is_open`, `sensor_motion` do **not** go through the field
  accessor (§4) — tick counter / a signal / units respectively.

★ **`is_ambient` is not static** (S8a finding): the site→tile map is static
(sample tiles are authored), but **values are always read live each tick** — no
per-level field snapshot is cached; nothing combat can mutate is memoized.

## 4. Sensor catalog (v1, design §6 — D7/D8/D9/D13, nit N3/N5)

All physical-by-default; `intangible` per instance. Each sensor declares a
`sample_tile` offset. **Sample family is per-channel (D7/D8):** air-resident
channels (`pressure`/`smoke`/`water_depth`/`o2`) sample the **faced air tile**
(dodging a solid body reading 0, design §5); solid-resident channels
(`temperature`/`fire`) sample the **body tile** where the field actually lives.
Behavior when a sample tile changes state is the honest reading of that tile.

Field sensors emit `value` (Q16.16). A **dead sensor emits 0** at 9e(a)
(D13 fail-deadly — never a stale last-reading). Optional `area` (length_m
radius): disc `dist < radius` (FieldEdit strict rule), masked to **currently
non-solid** tiles (via the frozen `solid` channel — D6), integer `area()` sum ÷
live non-solid count, **floor** (§6). `r_tiles`/disc quantized once at load
(editor §4 rule). The non-solid set legitimately changes when a wall in the
disc is destroyed — physics sensed, not drift.

- **`clock`:** emits `value` from an integer counter derived from the tick
  (period declared, snapped at load). No field read.
- **`door.is_open`:** not a class — the **door emits its `is_open` signal**
  (declared, inert in Arc A; 9e(a) drives it when wired). Wire
  `door_x.is_open → …` directly.
- **`sensor_motion`:** emits `value` = count of living units with
  `dist²(sensor_tile, unit_anchor) ≤ r_tiles²` AND (if `needs_los`)
  `has_los(sensor_tile → unit_anchor)` with the **sensor as Bresenham origin**
  (`has_los(fy_s,fx_s, fy_u,fx_u)`, asymmetric — origin pinned; stops on
  `solid`, so a shut door blocks sight — intended). **`unit_anchor` is pinned
  to the unit's anchor corner `(tile_y, tile_x)`** (D-nit N3 — one canon choice,
  not the center). `faction_filter = any | team-int` (unit `.team`);
  `min_footprint` compares the unit's declared `footprint`. Reads `sim.units`
  in unit-id order — deterministic, integer.

`hp_below`/`hostiles-of`/`chip.carried_by`/`win(...)` are **stack-2 riders**,
format-reserved, NOT built here.

## 5. The node set (design §4/§5 — D5, nit AND/SINGLE)

L0 node schema in `src/simulation/entities/nodes.py` (import-light) + runtime in
`src/simulation/logic_nodes.py` (gmap-free — pure SignalBus I/O per §4). Nodes
default physical, typically placed `intangible` per instance (design §5).

Building the node classes requires **extending `schema.py`** with the `AND` /
`SINGLE` input modes + the `_validate_class` mode guard (§2d) — do this in B2.

- **`decider`:** INPUT `in` (`SINGLE`). FIELDS `comparator`
  (enum `gt|ge|lt|le|eq|ne`), `threshold` (Q16.16, authored in the input's
  physical unit, quantized once at load by the meters-first rule), `require_alive`
  (bool, default false). SIGNAL `out` (0/1) = `cmp(in, threshold)` AND
  (require_alive ⇒ source alive). Prev-read/next-write.
- **`gate_and` / `gate_or`:** INPUT `in` (`AND` / `OR`, many wires). SIGNAL
  `out` (0/1) = all / any driving signals ≠ 0.
- **`gate_not`:** INPUT `in` (`SINGLE`). SIGNAL `out` = `1 - (in≠0)`.
- **`filter`:** INPUT `in` (`SINGLE`). FIELDS `tau_s` (length_m-style seconds).
  **`k` snapped once at load by EXACT integer/`Fraction` arithmetic (D5):**
  `k = ` the integer nearest `log2(τ·tps)` computed via `Fraction(str(tau_s))·tps`
  and `bit_length`/power-of-two comparison — **never float `log2`/`round`**
  (mirrors `door.quantize_span_tiles`; no float in the synced load path). k≥0;
  the editor shows the snapped effective τ. SIGNAL `out` (Q16.16). Integer EMA
  with shift `k`: state carries **k guard bits**, rounds-to-nearest before the
  shift (kills the truncation-park bug, design §4).

Node runtime state (EMA accumulator w/ guard bits, EDGE prev-values) are
**synced runtime rows** via each class's `runtime_digest_rows` (the A4
mechanism) — hashed, recorded, in `get_state`. They stay **absent (zero bytes)**
when the class isn't instantiated (dormancy). **The `door` class's
`runtime_digest_rows` is NOT extended** — `is_open` rides `__signals__` only,
never the `__entity__` block (D-nit N6); it stays exactly
`(state, want_open, hp_*)`.

## 6. The pump (N-feed actuator, design §6b — D10/D11)

Class `pump` (`entities/nodes.py` schema + a `pump_system.py` runtime). Post-EOS
the pump is a **gas-mass (N) feed**.

- INPUTS `inject`, `extract` (`OR`/held). FIELDS `rate` (atm/s), `target_atm`
  (Q16.16), `port_dx`/`port_dy` (the **port tile** offset — distinct from the
  solid body, else the skip-solid mask vetoes the pump's own edit). SIGNAL
  `at_target` (0/1, declared **hysteresis band** default ±0.05 atm — anti-
  chatter), `alive`.
- **Per-tick quantum `ΔN`** computed **once at load**: from `rate` via
  `ΔN = P/(C·T_std)` at standard temperature, integer Q16.16 (door-2 rule).
  **Load-time assert `ΔN_per_tick_atm < 2·hysteresis_band` (D11)** — else the
  step can jump the tile from below-band to above-band and `at_target` never
  latches → airlock deadlock. (At the default ±0.05 atm, `rate < 2·0.05·tps`.)
- **B4 builds a NEW integer, per-slice, zero-clamped gas-N primitive (D10)** —
  no existing primitive fits (`FieldEdit`'s gas path is a float bridge with a
  `[0,1]` clamp and optional RNG; `seal/unseal/destroy_wall` are redistribution/
  mint, not add/remove-N). **Inject:** add `ΔN` at the fixed standard O₂/N₂ mix
  at the port tile. **Extract:** remove `ΔN` **proportional to the tile's
  current composition** with `gas[g] = max(0, gas[g] − remove_g)` per slice —
  the explicit zero-clamp **before** the subtract lands, so N can never go
  negative into the Helmholtz solver. No RNG, no float bridge. Its own
  **N-conservation gate** (inject then extract round-trips; near-empty-tile
  boundary tested).
- Edits land at 9e(d) **before** the door sweep; reach the solver next tick.

Intent note (not a bug): a pump feeding a breached room makes venting
non-terminating (steady source vs vacuum sink). Correct physics — and the reason
the airlock must detect a breached door (D12, §7).

## 7. The automatic airlock_controller (design §6b; B5, HUMAN-TEST — D12, nit N5)

Class `airlock_controller` — an L0 **state machine** entity (SignalBus-only
I/O). Wired to: a chamber presence plate (`sensor_motion`) `in`; an **inner**
and **outer** door (drives `close`/`open`, reads each door's **`is_open` AND
`alive`** — D12); a **pump** (drives `inject`/`extract` open-loop); and — **B7,
Erik's Option 2** — a **chamber `pressure` sensor through two deciders**, read as
`at_far` (chamber ≤ far target) and `at_near` (chamber ≥ near target). Emits
`busy` (1 while cycling) + `alive`.

**v1 state machine** (single automatic cycle; the acceptance showcase):

```
IDLE            presence==0 → stay; ≥1 in chamber → CLOSING (busy=1)
CLOSING         drive both doors close; both (alive AND is_open==0) → EQUALIZE
                (a door that reads alive==0 is a BREACH, not sealed — abort to
                 FAULT, never pump into a hole — D12)
EQUALIZE        pump extracts; at_far (chamber ≤ far target, sensed) → OPEN_FAR
OPEN_FAR        drive far door open; presence==0 (chamber cleared) → RESEAL
RESEAL          drive far door close; (alive AND is_open==0) → REPRESSURIZE
REPRESSURIZE    pump injects; at_near (chamber ≥ near target, sensed) → IDLE
                (IDLE reopens the near door — the folded OPEN_NEAR step)
FAULT           breach detected: doors released to manual, busy=0, latch until reset
```

**Bidirectional (B7 — Erik's Option 2, the HUMAN-TEST revision):** the two legs
gate on the **chamber pressure sensor + deciders**, not the pump's single fixed
`at_target`. The pump runs open-loop (inject/extract as commanded);
`target_far_atm`/`target_near_atm` pick the drive DIRECTION per phase
(`equalize_cmd`), and the *sensor* decides when each leg is done — so
REPRESSURIZE genuinely refills (the B5 single-pump gap is removed, no
retargetable pump). State + dwell are **synced runtime rows** (integer). All
transitions read `pub` (prev-tick) and drive via wires — **no direct entity
references**, so list position is never observable. Timing/feel is Erik's
**HUMAN-TEST** gate; the state graph is deterministic and golden-testable.

**Fixture geometry (B7 bug fix):** the `levels/airlock_demo` corridor/chamber/
space is **5 tiles tall** — a 3×3 marine needs the full footprint clear to enter
a tile (`is_passable_block`), so a 3-tall corridor admits exactly one anchor row
and strands the unit (the HUMAN-TEST bug). 5 tall gives 3 valid anchor rows.
Doors span the full 5-tile opening; the pump (`rate=8`, `hysteresis_band` widened
to keep `ΔN<2·band`) evacuates/refills the 20-tile chamber in ~2 s each leg.

**Accepted v1 gaps (simplest honest design, documented so they're chosen):**
one chamber / two doors / one pump; level (not edge) triggers; no crush/anti-
cycle beyond occupancy-blocks-close. **Occupancy-blocks-close is a permanent
stall** (design §15.2 — living units block a close, no timeout): a unit parked
in a doorway hangs CLOSING indefinitely. **The presence plate MUST be placed off
the door spans** (nit N5) — else the unit that triggered the cycle blocks its
own airlock. A re-entering unit just holds the machine in its current wait state.

## 8. Digest, recorder, dormancy (D1/D2 — escalation-trigger 3)

- **`__signals__` populated (SIGNAL_SECT_V1):** at snapshot, emit
  `(emitter_ordinal, signal_name, pub_value)` for every non-`alive` slot **in
  the bus** (which exists only when logic exists — D1), sorted `(ordinal, name)`
  — exactly what `serialize_signal_state` expects. `alive` stays excluded
  (hashed only as the `__entity__` row, critique 7).
- **Node/pump/airlock runtime state** joins `__entity__` via
  `runtime_digest_rows`; the door's rows are unchanged (D-nit N6).
- **Recorder:** the signal payload stays **absent (None)** for dormant levels,
  exactly like today; `serialize_entity_state` is **NOT** extended to fold
  signals (that would change every door level's recorded `.npz` bytes) — signals
  ride the carrier's `signals` field, present only when the bus exists (D-nit N5).
- **Dormancy proof (the gate):** a level with **no `[[wire]]` and no
  logic/sensor entities has NO bus** → `get_state`/recorder pass `signals=()` →
  `serialize_signal_state(()) == b"SIGNAL_SECT_V1\n"` (Arc A's stable empty) →
  and no new runtime rows → **byte-identical** digest to today. Door-only levels
  (`test_level`, `door_test`) keep their door sweep (gated on `_doors`, D2) and
  emit **no** `is_open` into `__signals__` (no wire ⇒ no slot, D1) → unchanged.
  **No re-baseline** (escalation trigger 3). The per-patch gate is a
  **door-present, wire-free fixture** whose `tick_digest` is byte-identical
  pre/post-Arc-B (the actual fragile case — an entity-free fixture would trivially
  pass and miss the regression, D-nit N4).

## 9. Determinism ledger

Integer-only (Q16.16); every sweep in **ordinal / member-ordinal order**; dense
frozen signal-slot & wire tables (no dict-order); sensors + alive/is_open
emitted before any node reads signals (no sensor↔node order coupling); nodes
prev-read/next-write (the order-independence proof); no RNG anywhere in the
logic path (the new gas-N primitive is RNG-free, unlike `FieldEdit`); timers/
edges are integer tick counts; the filter `k`-snap uses exact `Fraction`
arithmetic (no float in the synced load path). All new synced state (bus +
runtime rows) joins the digest + recorder.
