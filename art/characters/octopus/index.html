Patterns (#113)

Seven skins from one pattern table (scripts/pattern_math.py): the default plus six taken from real animals. Every pattern is drawn in rest-pose skin coordinates stored per vertex, so it stretches with the skin: arm patterns follow the arm's own length coordinate and shrink with its radius toward the tip, and the oral side and suckers are paler (countershading). Each game variant is the same game mesh with only its albedo re-baked (gloss in alpha unchanged). Hero renders are Cycles in the build's studio; the game bake is albedo only.

Rebuild: build_patterns.py (Blender, ~3 min for all seven) then package_patterns.py --root <breach> (seconds; makes the gitignored per-variant GLBs). See the README.

Inside Breach

The tool launches the actual game through its existing E2E driver. It replaces only the prototype’s pose input to UnitModelRenderer; the game’s shader, light field, camera, skinning and projected shadows draw these frames.

Prototype substitution applies to visible units for this process only. True model scale; camera zoomed for inspection. Source checkout: 2c560cd. No gameplay activation.
